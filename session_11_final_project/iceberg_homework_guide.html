ShopVN Final Project — Apache Iceberg Implementation Playbook

Mục tiêu: xây dựng Lakehouse local cho ShopVN bằng Apache Iceberg, Apache Polaris REST Catalog, MinIO, Spark, Trino và Airflow.

Phạm vi: đây là hướng dẫn để bạn tự triển khai và đối chiếu từng bước. Code trong file chỉ là code tham khảo; không phải pipeline đã được implement.

RAM Docker tối đa: 8 GB. Source Compose của session 11 giữ nguyên; pipeline dùng Compose riêng.

      https://repo1.maven.org/maven2/org/postgresql/postgresql/${POSTGRES_JDBC_VERSION}/postgresql-${POSTGRES_JDBC_VERSION}.jar

USER airflow
RUN pip install --no-cache-dir \
      pyspark==3.5.6 \
      apache-airflow-providers-trino==5.9.0 \
      requests==2.32.3 paramiko==3.5.1

Polaris persistent bootstrap checklist

  1. Init script tạo hai database airflow và polaris trong platform PostgreSQL.
  2. polaris-bootstrap chạy idempotently với cùng JDBC config như Polaris server.
  3. Lấy OAuth token bằng root principal.
  4. Tạo internal catalog shopvn_catalog với base location s3://shopvn-lakehouse/warehouse, endpoint client/internal đều là http://minio:9000 vì mọi client chạy trong Docker.
  5. Grant CATALOG_MANAGE_CONTENT cho catalog admin role. Với homework local có thể dùng bootstrap principal cho Spark và khóa Trino bằng iceberg.security=READ_ONLY; ghi rõ đây không phải production IAM.
  6. Restart Polaris và chứng minh catalog vẫn tồn tại.
curl --fail-with-body -X POST http://localhost:8181/api/catalog/v1/oauth/tokens \
  -d "grant_type=client_credentials" \

Catalog setup script tham khảo

#!/bin/sh
set -eu
apk add --no-cache jq >/dev/null

TOKEN=$(curl -sS --fail-with-body \
  -u "$POLARIS_CLIENT_ID:$POLARIS_CLIENT_SECRET" \
  -H "Polaris-Realm: $POLARIS_REALM" \
  -d grant_type=client_credentials \
  -d scope=PRINCIPAL_ROLE:ALL \
  http://polaris:8181/api/catalog/v1/oauth/tokens | jq -r .access_token)

STATUS=$(curl -sS -o /tmp/catalog.json -w '%{http_code}' \
  -H "Authorization: Bearer $TOKEN" \
  -H "Polaris-Realm: $POLARIS_REALM" \
  http://polaris:8181/api/management/v1/catalogs/shopvn_catalog)

if [ "$STATUS" = "404" ]; then
  curl -sS --fail-with-body -X POST \
    -H "Authorization: Bearer $TOKEN" \
    -H "Polaris-Realm: $POLARIS_REALM" \
    -H "Content-Type: application/json" \
    http://polaris:8181/api/management/v1/catalogs \
    -d '{"catalog":{"name":"shopvn_catalog","type":"INTERNAL",
      "readOnly":false,
      "properties":{"default-base-location":"s3://shopvn-lakehouse/warehouse"},
      "storageConfigInfo":{"storageType":"S3",
        "endpoint":"http://minio:9000",
        "endpointInternal":"http://minio:9000",
        "pathStyleAccess":true,"region":"us-east-1"}}}'
elif [ "$STATUS" != "200" ]; then
  cat /tmp/catalog.json
  exit 1
fi

GRANT_STATUS=$(curl -sS -o /tmp/grant.json -w '%{http_code}' -X PUT \
  -H "Authorization: Bearer $TOKEN" \
  -H "Polaris-Realm: $POLARIS_REALM" \
  -H "Content-Type: application/json" \
  http://polaris:8181/api/management/v1/catalogs/shopvn_catalog/catalog-roles/catalog_admin/grants \
  -d '{"type":"catalog","privilege":"CATALOG_MANAGE_CONTENT"}')
case "$GRANT_STATUS" in
  200|201|204|409) ;;
  *) cat /tmp/grant.json; exit 1 ;;
esac

Script dựa trên Management API pattern chính thức. Nếu Polaris 1.7 trả status/body khác, giữ nguyên mục tiêu idempotency nhưng điều chỉnh theo log và API của đúng image; không bỏ qua 401/403/5xx.

14. Step 12 — SFTP Bronze và checksum

import hashlib

def md5_stream(path, chunk_size=1024*1024):
    digest = hashlib.md5()
    with open(path, "rb") as f:
        while chunk := f.read(chunk_size):
            digest.update(chunk)
    return digest.hexdigest()

def verify_md5(csv_path, md5_path):
    expected = open(md5_path, encoding="utf-8").read().strip().split()[0]
    actual = md5_stream(csv_path)
    return expected.lower() == actual.lower(), expected, actual

import time
import requests

def call_batch(session, base_url, api_key, order_ids):
    if not order_ids or len(order_ids) > 50:
        raise ValueError("batch size must be 1..50")
    timeout_retries = 0
    server_retries = 0
    while True:
        try:
            r = session.post(
                f"{base_url}/v1/shipments/batch",
                headers={"X-API-Key": api_key},
                json={"order_ids": order_ids},
                timeout=(5, 35),
            )
        except requests.Timeout:
            if timeout_retries >= 3:
                return {"status":"timeout_exhausted", "order_ids":order_ids}
            time.sleep([1, 2, 4][timeout_retries])
            timeout_retries += 1
            continue

        if r.status_code == 200:
            # not_found IDs thường nằm trong payload 200; ghi riêng vào audit.
            return {"status":"success", **r.json()}
        if r.status_code == 404:
            return {"status":"not_found", "order_ids":order_ids}
        if r.status_code == 429:
            time.sleep(float(r.json().get("retry_after", 5)))
            continue
        if r.status_code >= 500:
            if server_retries >= 1:
                return {"status":"server_error", "order_ids":order_ids}
            server_retries += 1
            time.sleep(1)
            continue
        if r.status_code == 400:
            raise RuntimeError(f"client batch bug: {r.text}")
        r.raise_for_status()

Không collect() toàn bộ orders vào driver. Bounded batches, giới hạn concurrency và ghi request/error audit.

23. Step 21 — Trino reconciliation

WITH source_revenue AS (
  SELECT business_date, SUM(net_revenue) AS source_net
  FROM shopvn.silver.revenue_components
  GROUP BY business_date
), candidate_revenue AS (
  SELECT business_date, SUM(net_revenue) AS candidate_net
  FROM shopvn.work.gold_revenue_candidate
  WHERE run_id = '{{ params.run_id }}'
  GROUP BY business_date
), violations AS (
  SELECT s.business_date, s.source_net, c.candidate_net,
         c.candidate_net - s.source_net AS difference
  FROM source_revenue s
  FULL OUTER JOIN candidate_revenue c USING (business_date)
  WHERE s.business_date IS NULL OR c.business_date IS NULL
     OR ABS(COALESCE(c.candidate_net,0) - COALESCE(s.source_net,0)) > 0.01
)
SELECT COUNT(*) = 0 AS check_passed FROM violations;

SQLCheckOperator chỉ PASS khi query trả true. Công thức source phải phản ánh refund, payment/status và invalid-discount rules. Trino là READ_ONLY nên không thể tự publish Gold.
